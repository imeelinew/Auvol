Windows WinUI · 鼠标接管

连接 / 音频传输 / 状态 三块按现状保留，连 InfoBar 文案都不改。 鼠标作为第四个分组，插在音频传输和状态之间，用 WinUI 的卡片行 + SelectorBar，不另开窗口、不做向导。

入口

分组标题「鼠标接管」+ 总开关。关着时卡片只剩一行，不跟音频按钮抢视线。

切换

光标位置用和「传输方向」同款 SelectorBar，但放在另一个分组里，避免当成音频方向。

快捷键

默认 Ctrl+Alt+M，和 Mac 的 ⌃⌥M 是同一套物理键。两端键盘都能切，不依赖鼠标还在哪。

音频「停止传输」在此预览里是摆设，不会关掉鼠标
1

第四段，不改前三段

连接、音频传输、状态的行顺序和文案保持现在这样。鼠标不并进「传输方向」，也不占用绿色 InfoBar。

2

SelectorBar 表示光标位置

看起来像音频方向，但标题是「光标位置」，选项是设备名 Mac / Windows。点它等于按快捷键。

3

关着几乎不占地方

总开关关闭时折叠成一行，避免一个很少用的功能把 880px 窗口再拉长一截。

4

没有单独的设置页

快捷键更改就在这一行完成：点「更改」后监听下一组组合键。Mac 弹层同样这么做，两端操作对称。
