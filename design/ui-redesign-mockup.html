Auvol UI 整理方案预览

这一轮只做 UI 与文案调整，核心传输 / 跟随 / 恢复逻辑不动。Windows 保留现有 WinUI 卡片架构与视觉风格； macOS 保留菜单栏 popover。两端展示同一套用户可读状态；菜单栏图标改为 SF Symbol wave.3.forward（蓝 / 橙 / 红）。本页是静态 HTML 效果稿。

优化原则

统一信息，而不是统一控件外形

  • 相通字段：方向、连接状态、自动跟随耳机、播放/采集设备、信号、链路质量、网络路径（Mac）。
  • 保留控制：对端 IP、方向切换、开始/停止（Win）或暂停/退出（Mac）、缓冲目标滑杆（仅 Mac 接收）。
  • 默认隐藏：当前缓冲、输出/源周期、时钟校正、数据包速率、丢失/迟到、欠载、溢出、采集异常、原始统计串，以及 ALV2 · 采样率 · 声道。
  • 删废话：去掉各行说明性副标题；菜单栏去掉旧的箭头+波形+色点组合图标。
菜单栏图标

wave.3.forward 三态上色

  • 正常连接：蓝色
  • 暂停：橙色
  • 有问题：红色
  • 不再用绿色状态点，也不再叠箭头 / waveform 复合图标。
